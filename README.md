# PSDF Full-Stack JavaScript Coursework

Coursework and mini-projects from a PSDF full-stack web development course, moving from JavaScript basics to a MERN-style API and a real-time chat app.

## What's inside

| Folder | Contents |
|---|---|
| `functions/` | JavaScript functions, closures and Promises |
| `node/` | Node.js core: async file system, HTTP server |
| `express/` | Express + MongoDB (Mongoose) REST API with user and product routes, JWT auth (bcrypt, cookies) and an MCP server experiment |
| `react/` | React + Vite frontend |
| [`chatsocket/`](chatsocket/) | **ChatSocket**: real-time chat rooms with online users and typing indicators (React + Socket.IO). See its README. |

## Tech stack

JavaScript · Node.js · Express · MongoDB / Mongoose · JWT · React · Vite · Socket.IO

## Getting started

```bash
cd express
npm install
npm start
```

## Environment variables (express/)

`MONGO_URI`, `JWT_SECRET`, `NODE_ENV`
